# TeamSync – Real-Time Team Collaboration Platform

TeamSync is a real-time collaboration platform designed to help teams communicate and work together in a shared digital workspace. It brings together real-time messaging and collaborative code editing to support seamless coordination among team members.

The platform combines the MERN stack with Supabase to support a responsive collaboration experience and multi-tenant functionality.

## Key Features

- **Real-Time Communication:** Enables team members to communicate through real-time chat.
- **Collaborative Code Editing:** Provides a shared environment for team members to collaborate on code.
- **Multi-Tenant Architecture:** Supports organizing collaboration around separate teams or workspaces.
- **Full-Stack Architecture:** Integrates a modern frontend with backend services and database functionality.
- **Interactive User Experience:** Designed to make team collaboration and coordination straightforward.

## Tech Stack

| Category | Technologies |
|---|---|
| Frontend | React.js |
| Backend | Node.js, Express.js |
| Database and Real-Time Services | Supabase |
| Architecture | MERN Stack with Supabase integration |

## System Overview

TeamSync integrates frontend components, backend services, and real-time functionality to support collaborative workflows.

1. Users interact with the platform through the frontend.
2. Backend services handle application logic and communication with supporting services.
3. Supabase provides database and real-time capabilities where configured.
4. Real-time messaging and collaborative code editing enable team members to work together.

## Getting Started

### Prerequisites

Install the following before running the project:

- Node.js and npm
- Git

You may also need a Supabase project and the corresponding environment variables, depending on your configuration.

### Installation

Clone the repository:

```bash
git clone https://github.com/DivyaAnilaP/TeamSync-RealTime-Collabration.git
cd TeamSync-RealTime-Collabration
```

Install dependencies:

```bash
npm install
```

Configure the environment variables required by your application. For example, if your implementation uses Supabase, add the appropriate project URL and public client key to the environment file expected by your code.

Start the application using the development command defined in your `package.json`. For example:

```bash
npm run dev
```

The exact setup commands may vary depending on the repository structure and available scripts.
